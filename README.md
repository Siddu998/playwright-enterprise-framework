# Framework Architecture

Tests → Pages → Utilities → API Layer → Reports

The framework follows scalable modular architecture using Playwright with reusable Page Object Model implementation and integrated API automation support.

## UI Automation
Robust UI automation using Playwright with reusable page objects and utilities.

## API Automation
Integrated API validation with scalable request handling and response validation.

## Modular Architecture
Framework designed for easy maintenance and scalability across large applications.
